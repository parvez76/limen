Parvez playground 

  






  
What runs here: the real Parvez parser, its security checks and its Rust generator, compiled to WebAssembly. Your code never leaves this page.
  What doesn't: Rust's type and borrow checks need rustc; run parvez check after installing. One file at a time: imports need the CLI.

  
Found a way to sneak request data, SQL or a secret past the checks? That's the most useful report there is: add it to the corpus. Known blind spots are in the known_miss example.
