Parvez

A small language for HTTP services and command-line tools. It compiles to plain Rust.

Its compiler always runs a fixed set of security checks: a route without an access policy, SQL built from strings, request data reaching the filesystem or a process, and secrets reaching logs are build errors. Each check has documented limits.

Status: experimental and pre-1.0. One maintainer, not independently audited.

Try it in your browser → The real compiler, running here: write a route, watch it refuse the insecure version. No install.

Why a language, and not a Rust crate? The honest answer, starting with what Rust tools already do well.

Install

Linux (x86_64, ARM64) and macOS (Apple silicon):

curl -fsSL https://parvez76.github.io/parvez/install.sh | sh

Windows (beta), in PowerShell:

irm https://parvez76.github.io/parvez/install.ps1 | iex

The installer checks the download against the release's SHA256SUMS (and its signed build attestation when the gh CLI is installed), puts parvez in ~/.parvez/bin, and offers to set up the Rust toolchain if it's missing. Read them first: install.sh, install.ps1.

Start

parvez doctor              # check the setup
parvez new hello && cd hello
parvez test main.prvz      # tests
parvez run main.prvz       # http://localhost:8080

Later, parvez upgrade moves to the newest release, verified the same way.

What it is

  • Checks on every build, no off switch: access policy on every route, SQL built from strings, request data reaching std::fs or Command (followed through functions, modules, traits and stored state), and secrets reaching logs. The only waiver is @allow_insecure("reason"), which is printed on every build. What each check catches, and its limits.
  • Compact: a JSON service is 9 lines, where the equivalent hand-written axum service is 48 (both versions).
  • Written for agents: the spec is one file meant for an AI agent's context, and errors point at .prvz lines. Whether agents do better with it than with Rust hasn't been measured yet.
  • No lock-in: it compiles to readable Rust; parvez show prints it.

What it won't do

It won't catch your logic mistakes: if a guard returns the wrong answer, Parvez enforces the wrong answer. It runs on top of Rust, covers Linux, Apple-silicon Macs and Windows (beta), and is pre-1.0. The full list.
