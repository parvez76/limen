# Philosophy

Parvez is my hobby project. There is no rush to launch it. It's like an artwork of mine: I want to enjoy making it, and I'm not heading for a milestone or a deadline.

I want to create a legacy, because the era of computer engineering has changed. Everyone is focusing on improving AI. I am focusing on the language that AI writes: a language the compiler understands, a language the machine knows.

The machine doesn't know AI, does it? The processor, the kernel and the database don't care who wrote the code, a person or a model. They do exactly what the code says. The compiler is the one place where that code can be stopped before it becomes action. So that is where I put the rules.

Better models make mistakes rarer. A stricter language can make some mistakes impossible to write. I'm working on the second, because it doesn't expire when the next model comes out.

I want Parvez to be honest about what it is: humble and precise, so that an engineer who knows the field can see the difference in a few glances, and can also see the limits, because they are written down. Every claim should trace back to a check that runs, or a test that fails if the claim stops being true.

— Parvez
